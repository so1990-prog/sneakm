ニューバランス880は2010年に初めて発売されたウォーキングシューズ。

ウォーキングシューズの中では特に人気のモデルです。

特徴としては日本人の足にあったシルエットで、価格が安い点。

定期的にグレードアップされており、ニューバランスの定番スニーカーと言えるでしょう。

ちなみに880とよく似て、比較されるモデルが990v4です。

![ニューバランス990v4](/images/posts/880/117A1671.jpg)

## ニューバランス880と990v4の違い

ニューバランス880とニューバランス990v4の一番分かりやすい違いは**価格の違い**です。

880のほうが価格が安く、990v4のほうが価格が高くなります。

990v4が高い理由としてはアメリカで生産されているモデルだから。

反対に880は中国やベトナムなどのアジアで生産されているモデルのため価格が安くなります。

|  |  |  |
| --- | --- | --- |
|  | **880** | **990v4** |
| **生産国** | アジア製 | アメリカ製 |
| **価格** | 安い | 高い |

目安の価格としては990v4が2万円～3万円。

880が7,000円～11,000円。

個人的な意見ですが、履き心地にこだわる人や予算に余裕がある人は990v4のほうがおすすめです。

## 2013年から5年連続でウォーキングシューズとしてはナンバーワンの売上を維持

ニューバランス880はその価格と性能の良さから全国のスポーツショップを対象とした調査でウォーキングシューズの中で最も売れているシューズとされています。(矢野経済研究所)

2013年から2017年まで**継続して1位を獲得しており**、2018年の結果も今から楽しみです。

現在ファッションシーンでは880をあまり見かけませんが、今後は[996](/newbalance-sneaker/)や[574](/574vnclassic/)と同じく880もファッションシーンで活躍する日が近いでしょう。

## ニューバランス880は2018年に新作モデルが誕生

ニューバランス880は現在880v4と呼ばれる4代目が最新のモデルです。

以下、最新の880v4です。

以前の880と比べるとスタイリッシュな見た目になり、機能面もグレードアップしています。

ちなみに下の画像は880v3です。

880v3と880v4の機能面の大きな違いは使用されているソールテクノロジーです。

880v3では軽さを重視するレブライトというテクノロジーが搭載されていたのに対し、880v4では「TRU FUSE」と呼ばれる最新のテクノロジーを搭載。

これにより、クッション性やフィット性が向上。

より履きやすさを重視したスニーカーとなりました。
