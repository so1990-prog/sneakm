今回は福岡で一人暮らしをしていたぼくが**オシャレなメンズセレクトショップ**を紹介します。

なんせ会社の転勤で行っていたので、休日はほぼ一人でいろんな店に行っていました。

ユナイテッドアローズやシップスなど大手セレクトショップではなく比較的規模の大きくないショップをチョイスしています。

福岡で買い物を考えているメンズは参考にして下さい。

## 福岡セレクトショップ｜DICE＆DICE(ダイスアンドダイス)

[![ダイスアンドダイス](/images/posts/fukuoka-menz/40da51492ac40adb2294b25ccdac4e88.jpg)](/wp-content/)

http://afro-fukuoka.net/archives/spot/dice-diceより

ダイスアンドダイスはぼくが福岡県内で見たセレクトショップの中では一番”欲しくなるアイテム”が多かったお店。

全国的に見てもおしゃれな人が特に好むショップでしょう。

その代わり、値段もそこそこするアイテムがほとんど。

安くて良い物を探している場合は他をあたった方が良いでしょう。

ちなみに、ぼくが愛用していた[エドロバートジャドソン](/edrobertjudson-wallet/)の財布はダイスアンドダイスで購入。

ショップ自体が本当におしゃれなので、置いてあるアイテムも自然とおしゃれに見えてきます。

|  |  |
| --- | --- |
| **営業時間** | 12：00～20：00 |
| **定休日** | なし |
| **公式リンク** | - [公式サイト](https://www.dicexdice.com/) - [インスタグラム](https://www.instagram.com/diceanddice/) |
| **取扱いブランド** | - nanamica - ED ROBERT JUDSON - YAECA - TONE - silent sound - rajabrooke etc. |
| **住所** | [福岡市中央区今泉２丁目１−４３ DXD bldg](https://goo.gl/maps/bZzq3twDEekEmRrc8) |
