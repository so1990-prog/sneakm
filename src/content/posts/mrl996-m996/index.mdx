しかし、MRL996が安いことにもM996が高いことにもちゃんとした理由があります。

まずは簡単に違いを比較してみます。

|  |  |  |
| --- | --- | --- |

| **サイズ** | 男女兼用 | メンズのみ |

簡単な違いが分かった所でそれぞれの違いをさらに詳しく見ていきましょう。

## MRL996とM996の価格(生産国)の違い

まず、2つの996の違いといえば価格の違いです。

**価格に大きな違いがある理由として「生産国の違い」があげられます。**

|  |  |  |
| --- | --- | --- |
| **MRL996** | アジア | 安価 |
| **M996** | アメリカ | 高価 |

MRL996はアジア製で中国やベトナムで大量生産されているスニーカーです。

それに対してM996はアメリカのニューバランス工場で一つ一つハンドメイドで作られています。

そのためMRL996とM996では一足に掛かるコストが違うのです。

**当然作るのに時間が掛かる「M996」の方がコストが掛かり価格も高くなります。**

### M996のシュータンにはUSAのラベルがある

M996はスニーカーのシュータン(ベロ)の部分に「MADE IN U.S.A」のプリントがあります。

![M996生産国](/images/posts/mrl996-m996/DSC03192.jpg)

当たり前ですがアジア製のMRL996には「MADE IN U.S.A」のプリントはありません。

![MRL996生産国](/images/posts/mrl996-m996/DSC03193.jpg)

また、これはニューバランスの豆知識ですがM996とMRL996の「NB」のロゴにも違いがあります。

NにかかるラインがM996は8本。MRL996は4本です。

ニューバランススニーカーは高額なモデルの方がこのラインが多い傾向があります。

もちろん、これによってデザインが大きく変わるわけではありませんが、知っているとニューバランスの購入がちょっとだけ楽しくなります。

## M996とMRL996のソールの違い

MRL996とM996は全体の見た目はほとんど同じですが、**スニーカーの土台部分のソールには違いがあります。**

![MRL996、M996違い](/images/posts/mrl996-m996/ae46b1f460ee46f789c27b264a6cb421.jpg)

上M996(ENCAP)、下MRL996(REVLITE)

上のM996のソールはENCAP。下のMRL996はREVLITEと表記されています。

- **MRL996****(レブライト)** ｜軽さを追求したソール。耐久性やクッション性にも優れている。ニューバランススニーカーの安価なモデルに使用されているソール。
- **M996****(エンキャップ×シーキャップ)** ｜2つのソールが一体化されている。クッション性、衝撃吸収性、安定性、全体的にハイレベルなソール。

ソールの違いによって履き心地は大きく異なります。

M996とMRL996は同じ996でも全く違う履き心地です。

できれば2つのモデルを履き比べてから購入することをおすすめします。

## M996よりもMRL996のほうが軽い

ソールの違いにより、2つの996は重さが異なります。

- **MRL996** めちゃくちゃ軽い
- **M996**     普通に軽い

2つの重さを比較するとその差は歴然。

M996よりもMRL996のほうが軽いです。

MRL996はニューバランススニーカー全体で見ても軽いモデルとなります。

また、軽いのはMRL996ですがクッション性が強いのはM996です。

M996の包み込まれるような柔らかい履き心地は、ニューバランススニーカー全体で見ても優れています。
